# Apache Kafka

## Scenario problem statement

A smart city traffic control center receives continuous vehicle-count and traffic-speed data from sensors installed at major junctions. It needs to identify congestion-prone roads and generate timely alerts for traffic operators.

## Expected outcome

Build a Kafka producer-consumer prototype demonstrating continuous traffic data ingestion and congestion alert generation.
