# Apache Hive

## Scenario problem statement

A supermarket chain generates millions of sales transaction records daily. Management wants to identify best-selling products, peak sales hours, branch-wise revenue, and monthly sales trends to improve inventory planning and business decisions.

## Expected outcome

Develop a Hive-based sales analysis report containing queries, sample outputs, and business insights.

## Files

- `Outcome_Report.docx` — this activity’s problem, implementation, results, analysis, and conclusion.
- `code/` and `data/` — only the code and synthetic input data for this technology.
- `docker-compose.yml` — isolated local service configuration when applicable.

## Demo

Hive sales data is mounted inside the container at /data/hive_sales. Run the provided HiveQL script and review product revenue/units, branch totals, transaction-hour counts, and monthly trend.
