# Big Data Systems Assignment

The five expected outcomes are separated into independent folders. Each folder contains that activity’s problem statement, expected outcome, activity report, source files, synthetic input data, and a short demo guide.

- `01_Hive_Sales_Analysis` — Hive sales analytics
- `02_Kafka_Traffic_Alerts` — Kafka traffic producer/consumer
- `03_Flink_Patient_Vitals` — Flink patient-vitals stream processing
- `04_MongoDB_Product_Catalog` — MongoDB product catalog CRUD and indexes
- `05_Cloud_Log_Analytics` — local cloud log analytics proof of concept

`Consolidated_Report.docx` contains the complete report. Open each activity folder and follow its `README.md` to demo that outcome independently. Inputs are synthetic. Patient-vitals thresholds are educational examples only.
